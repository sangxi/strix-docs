🍎 macOS 部署

支持 macOS 11 (Big Sur) 及以上，Intel 与 Apple 芯片（M 系列）都支持，脚本会自动挑对二进制。

芯片（Intel / Apple）怎么选

uname -m芯片产物
x86_64Intel（Core i5/i7/i9、Xeon）strix-server-darwin-amd64
strix-agent-darwin-amd64
arm64Apple M1 / M2 / M3 / M4strix-server-darwin-arm64
strix-agent-darwin-arm64
方向是单向的

Apple 芯片跑 amd64 版本有 Rosetta 2 兜底，能跑但多一层翻译； 反过来 Intel Mac 跑 arm64 版本完全跑不起来，系统会提示 Bad CPU type in executable。

安装脚本会自己 uname -m 后去同目录找对应文件，所以两个文件都拷过去最省事； 只拷一个也行，指定 -f 路径即可。

快速开始

# 把二进制和 deploy/macos 目录一起拷到 Mac（二进制会自动按芯片挑）
cd deploy/macos
chmod +x install.sh
sudo ./install.sh

脚本会自动：

  1. uname -m 判断芯片 → Intel 用 strix-server-darwin-amd64，M 系列用 -arm64
  2. 装到 /usr/local/strix/strix-server
  3. 生成配置 /usr/local/etc/strix/strix.env（权限 600）
  4. 注册 launchd 守护 com.strix.server（开机自启 + 崩溃自动拉起）
  5. 若系统防火墙开着，自动为本程序放行入站
  6. 打印只显示一次的控制台账号与通信密钥
为什么用 launchd 而不是 nohup

macOS 上只有 launchd 托管的进程才能可靠地开机自启并自动重启。

常用参数

sudo ./install.sh -f ./strix-server-darwin-arm64   # 指定二进制
sudo ./install.sh --addr :8000                          # 换端口
sudo ./install.sh --token '你的密钥' --admin-pass '你的密码'
sudo ./install.sh --public-url http://10.0.0.5:9999
sudo ./install.sh --uninstall                           # 卸载（保留数据）

目录规划

路径用途
/usr/local/strix/strix-server主程序
/usr/local/strix/start-server.shlaunchd 调用的包装脚本（加载配置后 exec 主程序）
/usr/local/strix/data/strix.dbSQLite 数据库
/usr/local/strix/logs/server.log程序日志
/usr/local/etc/strix/strix.env配置（权限 600）
/Library/LaunchDaemons/com.strix.server.plistlaunchd 单元

日常运维

# 日志
tail -f /usr/local/strix/logs/server.log

# 状态
sudo launchctl print system/com.strix.server | head -20

# 重启 / 停止 / 启动
sudo launchctl kickstart -k system/com.strix.server
sudo launchctl bootout system/com.strix.server
sudo launchctl bootstrap system /Library/LaunchDaemons/com.strix.server.plist

# 临时禁用开机自启（不禁用当前运行）
sudo launchctl disable system/com.strix.server

手工部署（不用脚本）

sudo mkdir -p /usr/local/strix/{data,logs} /usr/local/etc/strix
sudo install -m 0755 strix-server-darwin-arm64 /usr/local/strix/strix-server
sudo cp ../linux/strix.env.example /usr/local/etc/strix/strix.env
sudo vi /usr/local/etc/strix/strix.env     # 改 STRIX_TOKEN / STRIX_ADMIN_PASS
sudo chmod 600 /usr/local/etc/strix/strix.env

# 包装脚本：launchd 不读环境文件，必须先 source 再 exec
cat > /usr/local/strix/start-server.sh <<'EOF'
#!/bin/sh
set -a; [ -f /usr/local/etc/strix/strix.env ] && . /usr/local/etc/strix/strix.env; set +a
exec /usr/local/strix/strix-server
EOF
sudo chmod 755 /usr/local/strix/start-server.sh

sudo launchctl bootstrap system /Library/LaunchDaemons/com.strix.server.plist

常见排障

现象处理
提示「无法打开，因为 Apple 无法检查其是否包含恶意软件」二进制是自行编译未签名的：sudo xattr -dr com.apple.quarantine /usr/local/strix/strix-server
launchctl bootstrap 报 Bootstrap failed: 5单元文件语法或权限问题：确认属主 root:wheel、权限 644；先 bootout 再重试
服务反复重启看 logs/server.log；常见是端口占用或数据目录权限
别的机器打不开页面系统设置 → 网络 → 防火墙，确认本程序已允许传入连接
Apple 芯片误用 Intel 版报 Bad CPU type in executable。换 darwin-arm64 重新执行
启动日志指纹不是 278D-4852-7191-E7CE二进制不是本版本产物
