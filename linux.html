🐧 Linux 服务器部署

一句话结论：主流发行版全都兼容，一个脚本自适应发行版、架构、init 系统与防火墙。

为什么不用按发行版准备不同文件？

本程序是 CGO_ENABLED=0 编译的纯静态链接 Go 二进制。实测校验：

program headers: LOAD / NOTE / PHDR / GNU_STACK   <- 没有 PT_INTERP、没有 DYNAMIC
PT_INTERP 存在? False
引用 ld-linux? 0    引用 libc.so? 0    引用 ld-musl? 0

即不依赖 glibc 版本、不依赖任何系统库。唯一因发行版而异的，是「怎么注册成开机自启服务」「怎么放行端口」，这两件事脚本已自动适配。

架构（amd64 / arm64）怎么选

Linux 只有两个产物，按 uname -m 选：

uname -m选这个文件常见机器
x86_64strix-server-linux-amd64Intel / AMD 服务器、绝大多数云主机
aarch64（也写作 arm64）strix-server-linux-arm64鲲鹏 920、飞腾、倚天 710、树莓派 64 位系统
armv7l / i686没有对应产物32 位系统：请改装 64 位系统
armv7l 不是 arm64

armv7l 是 32 位的 ARM（常见于 32 位 Raspberry Pi OS、部分国产瘦客户端）， arm64 产物在它上面会报 Exec format error。本项目只发布 64 位产物， 这种情况请直接重装 64 位系统，不要尝试找 arm 版本。

快速开始

把二进制和 deploy/linux 目录一起传到服务器，然后执行安装脚本：

# 0) 先确认架构，别下错文件
uname -m          # x86_64 -> amd64 ; aarch64 -> arm64

# 1) 上传（在本地执行，按上一步的结果选文件）
scp -r deploy/linux strix-server-linux-amd64 root@10.0.0.5:/root/

# 2) 在服务器上执行
cd /root && chmod +x linux/install.sh
sudo ./linux/install.sh

脚本会自动完成：探测架构 → 校验传入的二进制确实是 Linux ELF（防止误拷了 Windows/macOS 产物）→ 建低权限用户 strix → 装到 /opt/strix/strix-server → 生成 /etc/strix/strix.env → 注册开机自启 → 放行端口 → 打印只显示一次的控制台账号与通信密钥。版本号以二进制自报的 -version 为准，不写死在脚本里。

装之前先自测一下

脚本只能判断「是不是 Linux 二进制」，判断不了「是不是当前 CPU 的架构」。装之前先跑一次：

./strix-server-linux-amd64 -version
# strix-server 1.2.2 (linux/amd64) 构建于 …   <- 括号里的架构要和 uname -m 对得上
# bash: ./strix-server-linux-arm64: cannot execute binary file: Exec format error  <- 架构错了
记下账号密码

控制台账号与通信密钥只在安装结束时打印一次。没记下也没关系：账号密码在 /etc/strix/strix.env，通信密钥可用 --token 重设。

常用参数

sudo ./install.sh --addr :8000                    # 换监听端口
sudo ./install.sh --token '你的通信密钥'            # 指定采集端要用的密钥
sudo ./install.sh --admin-pass '你的控制台密码'      # 指定控制台密码（否则随机生成）
sudo ./install.sh --public-url http://10.0.0.5:9999
sudo ./install.sh --no-firewall                   # 不动防火墙（自己管理）
sudo ./install.sh -f /tmp/strix-server-linux-arm64     # 指定二进制
sudo ./install.sh -u https://example.com/strix-server-linux-amd64   # 在线拉取
sudo ./install.sh --uninstall                     # 卸载（保留数据与配置）

参数也可用环境变量：STRIX_VERSION / STRIX_PREFIX。

目录规划

路径用途
/opt/strix/strix-server主程序（自动更新会替换它，旧版存为 .bak）
/opt/strix/data/strix.dbSQLite 数据库（WAL 模式，备份拷这个目录即可）
/opt/strix/releases/采集端发布物缓存（内网主机从这里升级）
/etc/strix/strix.env配置（权限 600，密码/密钥都在这里）
/etc/systemd/system/strix.servicesystemd 单元

日常运维

systemctl status strix --no-pager         # 状态
systemctl restart strix                   # 重启
systemctl disable --now strix             # 停止并取消开机自启
journalctl -u strix -f --no-pager         # 跟随日志
curl -s http://127.0.0.1:9999/api/health       # 健康检查

手工部署（不想用脚本时）

sudo useradd -r -s /sbin/nologin strix
sudo mkdir -p /opt/strix/{data,releases} /etc/strix
sudo install -m0755 strix-server-linux-amd64 /opt/strix/strix-server

sudo cp strix.env.example /etc/strix/strix.env
sudo vi /etc/strix/strix.env      # 至少改 STRIX_TOKEN 与 STRIX_ADMIN_PASS
sudo chmod 600 /etc/strix/strix.env

sudo cp strix.service /etc/systemd/system/
sudo chown -R strix:strix /opt/strix
sudo systemctl daemon-reload && sudo systemctl enable --now strix
sudo systemctl status strix --no-pager

升级与自重启

1.1.3 起，控制台「在线升级」换完二进制会自动重启生效，不再需要人工 systemctl restart：

启动方式自重启机制
systemd（unit Restart=always、RestartSec=5）进程退出，systemd 用新版本拉起
Docker Compose（restart: unless-stopped）容器 PID 1 退出，compose 重启容器
手工 nohup自行拉起同参数新进程后退出（端口被占用会自动重试，最多 20 秒）
用 -hub-restart 控制是否自动重启

auto（默认，自动重启生效）/ off（只替换文件不重启，需自己重启）。 新版本启动失败会自动回滚到 .bak。

手工替换二进制升级（务必按序）

  1. 备份旧二进制：cp /opt/strix/strix-server /opt/strix/strix-server.bak-$(date +%F)
  2. 删除待生效标记：rm -f /opt/strix/.strix-server.pending（不清掉的话启动时会认为上次升级未生效而回滚到 .bak）
  3. 替换二进制并赋可执行：install -m0755 新二进制 /opt/strix/strix-server
  4. 重启：systemctl restart strix
  5. 校验：/opt/strix/strix-server -version

常见排障

现象原因与处理
journalctl 里 avc: deniedSELinux：semanage fcontext -a -t bin_t '/opt/strix(/.*)?' && restorecon -R /opt/strix 后重启
permission denied 启动失败属主不对：chown -R strix:strix /opt/strix
本机能开、外面打不开firewalld/ufw 未放行，或云服务器安全组未放行 9999
address already in usess -tlnp | grep 9999 找占用进程，或换 --addr :8000
日志报「打开数据库失败」STRIX_DB 指向的目录不存在或无写权限
CentOS 7 systemd 报 Unknown lvalue LimitNOFILE老 systemd 语法差异，删掉该行即可（非必需）
想完全离线ExecStart 加 -hub=。不能用 STRIX_HUB=（空串会回落默认地址）
