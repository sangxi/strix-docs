⚙️ 配置项清单

每个参数都有「命令行 flag」与「环境变量」两种给法，二者等价。优先级：命令行 > 环境变量 > 默认值。

重要：环境变量设空串等于没设

配置读取逻辑对空字符串会回落到默认值。所以 STRIX_HUB=（想关掉授权中心）是无效的， 必须用启动参数 -hub=。

监控端 strix-server

参数环境变量默认值说明
-addrSTRIX_ADDR:9999HTTP 监听地址
-dbSTRIX_DB./data/strix.dbSQLite 文件路径（仅 SQLite，无 MySQL 后端）
-tokenSTRIX_TOKENstrix采集端通信密钥，两端必须一致
-userSTRIX_ADMIN_USERadmin控制台账号（仅首次启动生效）
-passSTRIX_ADMIN_PASSstrix控制台密码（仅首次启动生效）
-retentionSTRIX_RETENTION30历史数据保留天数，0 表示永久
-public-urlSTRIX_PUBLIC_URL自动反推对外访问地址，反向代理下务必显式指定
-offlineSTRIX_OFFLINE_SEC180超过该秒数未上报判定离线
-cpu-alertSTRIX_CPU_ALERT90CPU 告警阈值（%）
-mem-alertSTRIX_MEM_ALERT90内存告警阈值（%）
-disk-alertSTRIX_DISK_ALERT90磁盘告警阈值（%）
-load-alertSTRIX_LOAD_ALERT10系统负载告警阈值
-alert-cooldownSTRIX_ALERT_COOLDOWN_MIN10同类告警去重冷却（分钟）
-read-connsSTRIX_READ_CONNS8SQLite 读连接池大小
-write-queueSTRIX_WRITE_QUEUE8192指标写入队列长度
-probe-workersSTRIX_PROBE_WORKERS64服务端探针并发Worker数
-purgeSTRIX_PURGE_INTERVAL3600历史数据清理间隔（秒）
-login-alertSTRIX_LOGIN_ALERTtrue控制台登录失败是否发告警
-allow-commandSTRIX_ALLOW_COMMANDtrue是否允许向采集端下发 shell 指令
-release-dirSTRIX_RELEASE_DIR空采集端发布物缓存目录（默认程序同目录 releases/）
-free-hostsSTRIX_FREE_HOSTS10免费版主机额度
-free-usersSTRIX_FREE_USERS3免费版用户额度
-hubSTRIX_HUB默认内置授权中心地址授权/版本同步中心；要完全离线请用 -hub=（默认地址已内置，无需手动填写）
-hub-tokenSTRIX_HUB_TOKEN空访问授权中心的 token（仅授权端侧需要）
-hub-intervalSTRIX_HUB_INTERVAL_MIN5与授权中心同步间隔（分钟）
-hub-auto-updateSTRIX_HUB_AUTO_UPDATEdownload平台自升级策略：download 自动下载并就位（就位后自动重启生效）/ check 只提示 / off 关闭
-hub-restartSTRIX_HUB_RESTARTauto自升级后是否自动重启生效：auto（默认，自动重启）/ off（只替换文件不重启）
-hub-uaSTRIX_HUB_UA空访问授权中心时使用的 User-Agent
-license*STRIX_LICENSE_*空授权相关配置（含兼容旧格式 HMAC 授权码的 STRIX_LICENSE_SECRET，对应 WGC-/OPSM1-/OPSM- 授权码）
-version——打印版本号并退出

Docker 相关（.env）

变量说明
STRIX_ADMIN_PASS / STRIX_TOKEN控制台密码与通信密钥
STRIX_PUBLIC_URL对外访问地址（含域名时必设）
STRIX_LICENSE_MACHINE固定容器机器码，避免重建后授权失效
TZ时区，建议 Asia/Shanghai
VERSION构建镜像时选用的 release/<版本>/ 目录

给法示例

# 命令行
./strix-server -addr :9999 -db /opt/strix/data/strix.db \
  -token 'my-secret' -public-url http://10.0.0.5:9999 -hub=

# 环境变量（等价）
export STRIX_ADDR=:9999
export STRIX_DB=/opt/strix/data/strix.db
export STRIX_TOKEN=my-secret
export STRIX_PUBLIC_URL=http://10.0.0.5:9999
./strix-server
# 注意：离线要用 -hub=（不能靠 STRIX_HUB= 空串）
存储说明

监控端自身存储只有 SQLite（纯 Go 实现，无需 CGO）。-db 只能改 SQLite 文件路径， 不存在 MySQL 存储后端。工程里出现的 MySQL 驱动只服务于「数据库监控项」的探测目标。
